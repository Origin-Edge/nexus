Entegrasyon & Kullanım Kılavuzu

Base URL: http://localhost:3050/v1

Ürettiğiniz herhangi bir Nexus API anahtarını Authorization: Bearer nx-live-... başlığı ile cURL, Python openai paketine veya Node.js istemcisine geçebilirsiniz.

cURL İstek Örneği
curl http://localhost:3050/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen2.5-coder:7b",
    "messages": [{"role": "user", "content": "Merhaba!"}]
  }'
Python OpenAI SDK
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:3050/v1",
    api_key="YOUR_API_KEY"
)

res = client.chat.completions.create(
    model="qwen2.5-coder:7b",
    messages=[{"role": "user", "content": "Merhaba!"}]
)
print(res.choices[0].message.content)
